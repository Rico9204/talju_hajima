# 동료 평가 0점 허용

중간·최종 평가의 항목별 점수 범위는 정수 0~10점입니다. 항목별 합계는 기존대로 동료 수 × 5점이어야 합니다. 예를 들어 동료가 2명이면 한 항목에 0점과 10점을 배분할 수 있습니다.

## 기존 DB 적용

프런트엔드 배포 전에 Supabase SQL Editor에서 `supabase/migration_evaluation_zero_scores.sql`을 실행합니다. 기존 동료 평가 및 프로토타입 마이그레이션이 적용된 DB를 대상으로 합니다.

이 마이그레이션은 5개 점수 제약과 제출 함수의 하한을 0으로 변경합니다. 기존 데이터, 접근 정책, 프로토타입 활성화 여부와 평가 시기 제한은 유지합니다. 적용하지 않으면 화면에서 선택한 0점을 DB가 거부합니다.

새 DB의 `supabase/schema.sql`에도 0~10점 범위가 반영되어 있습니다. 기존 마이그레이션을 순서대로 사용하는 경우 0점 마이그레이션을 마지막에 적용합니다.

## 검증

- 오각형 중앙의 0점 입력 및 상하한 테스트
- DB 통합 테스트: 0점·10점 저장, 음수 거부, 총점 검증, 평균 반영, 평가 시기 제한 유지
- TypeScript 검사 및 프로덕션 빌드
