# 한컴독스(Web HWP) 기능 체크리스트

> 첨부된 한컴독스(`webhwp.hancomdocs.com`) 에디터 스크린샷 10장을 기준으로 메뉴·도구 상자·상태 표시줄·단축키를 정리한 기능 체크리스트입니다.
> (`▶` 표시는 하위 메뉴가 있는 항목, 괄호는 스크린샷에 표시된 단축키입니다.)

---

## 1. 에디터 전체 레이아웃 및 도구 상자

- [ ] **상단 헤더**
  - [ ] 문서 제목 표시 (`한컴오피스_기능테스트_문서`)
  - [ ] 공유 버튼
  - [ ] 데스크톱에서 편집 버튼
- [ ] **기본 도구 상자 (1단 아이콘 줄)**
  - [ ] 저장하기
  - [ ] 오려 두기 / 복사하기 / 붙이기
  - [ ] 모양 복사
  - [ ] 찾기
  - [ ] 도형 / 그림 / 표 / 차트 / 웹 동영상
  - [ ] 각주 / 미주
  - [ ] 하이퍼링크 / 문자표
  - [ ] 글자 모양 / 문단 모양 / 개체 속성
  - [ ] 머리말 / 꼬리말
  - [ ] 조판 부호 / 문단 부호 / 격자 보기
  - [ ] 공공안심글꼴
- [ ] **서식 도구 상자 (2단 아이콘 줄)**
  - [ ] 되돌리기 / 다시 실행
  - [ ] 스타일 선택 (`Normal` 등)
  - [ ] 글꼴 종류 / 대표 글꼴 선택 (`대표`, `함초롬바탕` 등)
  - [ ] 글자 크기 (`10.0 pt` 등)
  - [ ] 글자 크기 크게 / 작게
  - [ ] 굵게 / 기울임 / 밑줄 / 취소선 / 글자색 / 강조(형광펜) 등 글자 서식
  - [ ] 문단 정렬 (양쪽 / 왼쪽 / 가운데 / 오른쪽 / 배분 등)
  - [x] 줄 간격 (`160 %` 등)
  - [ ] 문단 번호 / 글머리표 / 수준 증가·감소
- [ ] **편집 영역 UI**
  - [ ] 가로 눈금자 (여백·들여쓰기·탭 조절)
  - [x] 쪽 윤곽 표시 (용지 네 모서리 여백 안내선 `└ ┘ ┌ ┐`)
- [ ] **하단 상태 표시줄**
  - [ ] 현재 쪽 / 전체 쪽 (`1/3 쪽`)
  - [ ] 글자 수 (`3182 글자`)
  - [ ] 구역 (`구역: 1/1`)
  - [ ] 입력 모드 (`삽입` 등)
  - [ ] 변경 내용 추적 상태 (`변경 내용 [기록 중지]`)
  - [ ] 보기 모드 전환 버튼 및 확대/축소 슬라이더 (`100%`)
