# 프로토타입 평가 모드

동료 평가 탭에서 중간 평가와 최종 평가를 선택합니다.
각 유형의 초안과 제출 내역은 분리되고, 탭 전환 시 입력한 점수와 의견이 유지됩니다.
프로젝트를 종료하지 않고도 최종 평가를 제출할 수 있습니다.
중복 제출 방지, 본인 제외, 프로젝트 참여자 확인, 항목별 합계 검증은 그대로 적용합니다.

## 적용
기존 평가 마이그레이션 이후 supabase/migration_evaluation_prototype.sql을 실행합니다.
새 DB의 schema.sql에도 포함되어 있습니다.
프로토타입 모드는 DB의 evaluation_prototype_enabled() 반환값으로 화면과 서버가 함께 판단합니다.
클라이언트에서 모드를 변경할 수는 없습니다.

프로토타입에서는:
- 프로젝트 상태와 2주 미만 제한에 관계없이 중간/최종 평가를 제출합니다.
- 중간 평가는 작성자와 받는 사람만 조회합니다.
- 최종 평가는 진행 중에도 팀 전체에 공개되고 기존 프로젝트별 평판에 반영됩니다.
- 저장은 실제 DB에 이루어지며, 테스트 전용 평가 데이터를 별도로 분리하지는 않습니다.

## 정상 모드 복원
DB 관리자가 아래 SQL을 실행하면 기존 상태/단기 프로젝트 제한이 다시 적용됩니다.
화면을 새로고침하면 유형 선택 탭이 사라지고 프로젝트 상태에 해당하는 평가만 표시됩니다.

```sql
create or replace function public.evaluation_prototype_enabled()
returns boolean language sql stable as 'select false';
```

기존 제출 데이터와 집계된 평판은 자동으로 삭제하거나 되돌리지 않습니다.
실제 날짜별 중간/최종 평가 기간을 세분화하는 기능은 별도 구현이 필요합니다.

## 검증
- 기존 검증 32개 + 프로토타입/정상 모드 복원 검증 12개, 총 44개 DB 테스트.
- TypeScript 검사와 프로덕션 빌드.
- 테스트 전용 브라우저 화면에서 유형 전환, 초안 유지, 각 유형의 독립 제출 검증.
