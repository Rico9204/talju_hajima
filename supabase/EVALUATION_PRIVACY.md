# 평가 결과 조회 권한 변경

1. 기존 평가 및 프로토타입 SQL 적용 후 migrations/2609162309_evaluation_privacy.sql 전체를 Supabase SQL Editor에서 직접 실행합니다.
2. 같은 배포 작업에서 이 브랜치의 프런트엔드도 배포합니다. 기존 클라이언트의 members 전체 열 조회는 권한 변경 후 실패하므로 SQL만 적용한 채 기존 버전을 계속 사용하면 안 됩니다.
3. 본인 중간 평균은 동료 평가 탭, 최종 평균은 대시보드·프로필에서 확인합니다.

- 원본 평가 SELECT는 본인이 작성한 평가만 허용합니다. 받은 원본 점수와 평가자 정보는 반환하지 않습니다. 중간 평가의 종합 코멘트만 평균 공개 조건을 충족한 본인에게 익명 목록으로 반환합니다.
- 최종 평가는 종합 코멘트를 저장하지 않으며, 기존 최종 코멘트도 이 SQL 실행 시 삭제됩니다.
- members의 평점 열 직접 조회를 차단합니다. 전용 함수는 타인의 평점 필드를 0/0건으로 가리고 본인에게만 집계값을 반환합니다.
- 프로젝트별 동료 2명 이상이 모두 제출한 경우에만 평균을 공개합니다. 평가 1건 또는 순차 제출에 따른 점수 추정을 줄이기 위한 조건입니다. 평균이라는 통계 자체와 외부 정보의 조합에 의한 모든 추론까지 방지하는 것은 아닙니다.
- 기존 SQL의 evaluation_read 정책을 다시 적용하면 권한이 되돌아갈 수 있으므로 개인정보 보호 SQL을 항상 마지막에 적용합니다.
- 원격 DB에는 자동 적용하지 않았습니다.
